# 🔐 password-checker

Şifre güvenlik analizi ve güçlü şifre üreticisi. Entropy hesabı, kural kontrolü.

## Kurulum
```bash
cargo build --release
```
## Kullanım
```bash
password-checker check "MyP@ssw0rd"
password-checker generate --length 20 --symbols
password-checker generate --count 5
```
